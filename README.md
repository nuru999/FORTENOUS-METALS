# Fortenous Metals Tanzania Company Limited - Corporate Website

A modern, responsive corporate website built for **Fortenous Metals Tanzania Company Limited**, a privately owned Tanzanian mining and industrial company.

## 📁 Project Structure

```
fortenous-website/
├── index.html          # Homepage - Hero, About preview, Values, Services, Contact CTA
├── about.html          # About Us - Company overview, Vision & Mission, Core Values, Legal structure
├── services.html       # Services - Primary & extended business areas, Financial services
├── contact.html        # Contact - Contact info, Form, Location
├── css/
│   └── style.css       # Main stylesheet - Dark theme with gold accents
├── js/
│   └── main.js         # Interactive features, animations, form handling
└── images/             # Folder for images (placeholders used)
```

## 🎨 Design Features

- **Dark Theme with Gold Accents** - Premium mining/metals industry aesthetic
- **Fully Responsive** - Works on desktop, tablet, and mobile devices
- **Smooth Animations** - Scroll reveal effects, hover animations, counter animations
- **Modern Navigation** - Fixed navbar with scroll effects and mobile hamburger menu
- **Interactive Elements** - 3D card tilt effects, form validation, smooth scrolling
- **Cross-browser Compatible** - Uses modern CSS with fallbacks

## 🚀 How to Use

### Option 1: Open Directly
1. Extract the `fortenous-website` folder
2. Double-click `index.html` to open in your default browser

### Option 2: Using VS Code Live Server
1. Open the `fortenous-website` folder in VS Code
2. Install the **Live Server** extension (if not already installed)
3. Right-click on `index.html` and select **"Open with Live Server"**
4. The website will open in your browser at `http://127.0.0.1:5500`

### Option 3: Using Python HTTP Server
```bash
cd fortenous-website
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser.
