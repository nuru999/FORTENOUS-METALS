# Fortenous Metals Tanzania

Investor-facing corporate website for **Fortenous Metals Tanzania Company Limited**, a Tanzanian private company limited by shares.

**Live site:** [nuru999.github.io/FORTENOUS-METALS](https://nuru999.github.io/FORTENOUS-METALS/)

## Purpose

The website presents the company’s legal foundation, strategic focus, leadership, licence-publication policy, and partnership contact route. It deliberately separates:

- authorised objects in the Memorandum of Association;
- current strategic focus;
- future intentions;
- verified licences, approvals, and project claims.

This distinction protects the company’s credibility and gives potential partners a clearer starting point for due diligence.

## Pages

| Page | Purpose |
| --- | --- |
| `index.html` | Company positioning, verified facts, partnership pathway, and licence status |
| `about.html` | Corporate foundation, leadership, strategic direction, and governance principles |
| `services.html` | Mineral value-chain focus and partnership opportunities |
| `licences.html` | Licence register structure, redaction policy, and document-request route |
| `contact.html` | Direct business contacts and a privacy-friendly email enquiry builder |

## Source discipline

The initial corporate facts are based on the company’s Memorandum and Articles of Association dated 26 May 2026. The website does not treat that document as proof of:

- incorporation on that date;
- an active mineral right;
- an environmental approval;
- a current mining operation;
- a public investment offering.

Licence and project information should be added only after management verifies the holder, authority, status, dates, scope, and permission to publish.

## Technology

- Semantic HTML5
- Responsive CSS
- Vanilla JavaScript
- GitHub Pages

No build step is required. The contact form stores no information; it prepares an email in the visitor’s email application.

## Run locally

```bash
git clone https://github.com/nuru999/FORTENOUS-METALS.git
cd FORTENOUS-METALS
python -m http.server 8000
```

Then open `http://localhost:8000`.
